# 日落之后 · AFTER THE SUNSET（原「眨眼之间」，更早叫「困倦的跑」）

> 名字取自整段旅程：迎着落日跑，日落之后，黄昏跑成了梦。

第一幕「清醒」原型，风机农场版为主体验。

两个版本，同一个交互骨架（手掌=摇杆+油门，眨眼悄悄计数）：

- **`model.html` — 风机农场版（主体验）**：加载你提供的 `models/已加速- Wind Turbine Farm.glb`，Three.js 渲染，人眼高度沿田野长轴**向前跑**，迎着落日从风机旁掠过，叶片转速跟随奔跑速度
- **`index.html` — 程序化黄昏公路版（对照/备用）**：纯 shader 生成的黄昏土路

## 怎么跑

摄像头需要 localhost 环境，两种方式任选：

- **macOS**：双击 `启动.command`（首次右键 → 打开，绕过 Gatekeeper）
- **通用**：在本目录执行 `python3 -m http.server 8787`，浏览器打开
  - 风机农场版：http://localhost:8787/model.html
  - 公路版：http://localhost:8787/

## 操作

| 动作 | 效果 |
|---|---|
| 左右移动掌心 | 转向 |
| 朝镜头方向推掌 | 加速奔跑（有惯性冲量） |

| 右上角 🔇 | 开关风声（音量随速度变化） |

## 模型版技术笔记（Wind Turbine Farm.glb）

- 157MB，23 张内嵌贴图，无动画；本地 localhost 加载约 3~8 秒
- **导出缺陷已在运行时归一化修正**（`model.html` 加载回调内写死的常量，基于实测）：
  - 场景根节点自带 +626.19 的 Y 偏移（原作地面高度），归零后地面落在 y≈0
  - 风机节点（0 基准顶点）被额外下沉 335.1，归位后塔基 y=0.5、塔顶≈205.5
  - 叶片是独立节点 `Fins`，装到塔顶+40m 处，绕 X 轴旋转，转速 = 0.6 + 速度系数×2.6 rad/s
  - 云层几何下探到地底，节点抬至 y=8426；自带"体积雾"大盒子直接隐藏（改用场景 Fog）
  - 注意 `gltf.scene` 名字就叫 "Wind Turbine Farm"，遍历匹配风机时必须排除根节点
- **农场密度**：原始风机作为模板被克隆成 30+ 台（近景大门一对、两侧主列 520m 间距交错、远景两排渐入雾中），每台叶片独立相位、转速跟随奔跑速度；干草垛克隆 27 个散布两侧。全部共享几何与材质，只增加 draw call
- 相机：人眼 2.2m，沿 +Z 主轴前进（START -1500 → END 5200，出界自动回绕），lookAt 前方 + 转向偏航 + 奔跑颠簸 + 速度感 FOV
- 尺度：1 单位 = 1 米（风机塔高 205m、转子半径 52m、田野约 6.8km × 12.8km）

## 与整体蓝图的关系

第一幕只建立「灵敏、信任」的手感基线（清醒 = 清晰、暖色、无延迟）。
已就绪、等待接入的后续机制：

- **第二幕·迟滞（已并入 model.html）**：眨眼数驱动困意进度（6 次到顶）→ 焦点圈从中心收缩（四周渐失焦）、模糊半径 2→15px、饱和度 −55%、眼睑软边合拢、雾逼近、速度衰减至 38%、输入延迟 0.12→0.82s（延迟队列）、风声低通变闷；所有视觉状态经 1.5s 平滑趋近，不跳变
- **握拳回退**：指尖收拢度（指尖-掌心距离/手掌尺寸）<0.42 判定握拳、握住 0.7s 触发，张开 >0.55 复位（带迟滞防误触）；困意 −1 格，全场特效平滑回退；最多 3 次，剩余次数在 HUD 显示；鼠标模式按 F 等效
- **日落之前（氛围系统）**：太阳随累计里程缓缓下沉（约 6.5km 沉入地平线，天空 shader 同步变暗变柔）；沿途出现**光门岔路**——穿过金门「麦浪」/蓝门「风起」，雾色与风铃随选择变化；每公里一句旁白短句；随机小事件：远处夜车驶过、鹿群横穿跑道、农场尽头的灯塔扫光
- **第三幕·入梦（已接入）**：困意顶点合眼全黑后「张开五指」→ 自动坠入第三幕星空小镇（`../act3/index.html`，需用 `act3/启动.command` 从项目根目录起服务，端口 8793）；第三幕里握拳 3s 惊醒回到本幕困意顶点，立刻合眼又回到梦中。测试键：D=直接入梦，惊醒态 E=模拟立刻合眼

## 已知限制

- 识别模型从 CDN 加载，首次运行需联网
- 强逆光 / 极弱光下眨眼阈值可能需要调（`detectBlink` 里的 0.5）
- 模型归一化常量与这份 GLB 绑定，换模型需重新标定（加载回调内的注释块）
